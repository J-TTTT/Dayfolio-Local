# 日序 · 本地工作台

在自己的电脑上记录日程、计划、工作、科研进展和灵感，按项目整理日报与周报。

## 开始使用

需要 Node.js 24 或更新版本。Windows 用户双击 **启动日序.cmd**，打开 <http://127.0.0.1:4317>，首次使用自行创建管理员账号。

也可以执行：

```sh
node server/server.mjs
```

已包含构建好的 `dist/`，运行时无需安装依赖或连接 Sites。修改前端源码时执行 `npm ci` 和 `npm run build`。运行测试：`npm test`。

## 功能

- 日程、计划、工作、科研与灵感记录。
- 项目名称、内容、进度、问题、解决方案和下一步。
- 五种灵感分类与主题筛选。
- 按项目汇总日报、周报，支持复制和 Markdown 导出。
- 本地账号、一次性邀请链接、账号间记录隔离。
- SQLite 持久化保存和手动数据库快照备份。

只监听本机地址。摘要基于记录和关键词整理，不使用外部 AI 服务；不发送邀请邮件。原 Sites 云端数据不会自动同步。

## 数据

数据库在 `data/dayfolio.sqlite`，备份在 `backups/`。这些目录和日志已通过 `.gitignore` 排除，不属于仓库内容。不要将个人数据库或备份提交到 GitHub。

完整启动、停止、备份和恢复方法见 [使用说明](使用说明.md)。
